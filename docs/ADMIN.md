# Admin guide

Open **/admin** (link appears in the header for moderators and above).

| Section | Who | What |
|---|---|---|
| Overview | admin+ | members, posts, open work, 14-day traffic & growth |
| Analytics | admin+ | views, visitors, top pages, referrers, devices, countries, UTM campaigns |
| Moderation | moderator+ | review reports → dismiss / resolve / delete content |
| Content | admin+ | publish, edit, pin, delete notices & study items (with deadlines) |
| Members | admin+ | search, suspend/restore (reason logged); Super Admin sets roles |
| Info Desk | admin+ | answer member requests |
| AI workflow | admin+ | feed freshness, refresh now, hourly run history |
| Settings | Super Admin | announcement banner, read-only mode, pause sign-ups, tagline, contact, social links |
| Audit log / Export | Super Admin | who did what; full JSON backup |

The legacy admission tracker (if you kept it) lives at `/private/admission-tracker` for the Super Admin only; put the file in `private/admission-tracker.html` (git-ignored) before building.
